# Task Manager

A simple and professional Task Manager web application built with React.

## Features

- Add new tasks
- Add tasks using Enter key
- Edit tasks
- Complete and undo tasks
- Delete tasks
- Search tasks
- Filter tasks by All, Active, and Completed
- Dark and Light mode
- LocalStorage data persistence
- Task creation date and time
- Responsive design for mobile devices

## Technologies Used

- React
- JavaScript
- HTML
- CSS
- Vite
- LocalStorage
